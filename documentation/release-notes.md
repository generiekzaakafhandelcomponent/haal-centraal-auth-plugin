# Release notes

Overzicht van wijzigingen per versie van de Haal Centraal Auth-plugin.

## 0.15.0

De frontend van de plugin wordt weer gebouwd en gepubliceerd. De `tsconfig`-verwijzingen van het
plugin-project wezen een map te hoog, buiten de repository, waardoor de build afbrak op een ontbrekende
`tsconfig.json`. Daarnaast volgt het versienummer nu de semver-notatie, die npm vereist.

## 0.14

Valtimo bijgewerkt naar versie 13.41.0.

## 0.9
Eerste publieke release: authenticatie voor Haal Centraal-API's voor de BAG- en BRP-plugins.
